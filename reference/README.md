# Source and change record

The user supplied a concept proposal as project context and separately required adhesive mounting, a first mechanical iteration in Fusion, and detailed repository documentation. The supplied screenshot showed Fusion MCP preferences. The open Fusion document was empty.

A later clarification explicitly required tape on **the plastic faceplate only**. The final v0.1 follows that clarification. The original proposal is not redistributed. It was treated as background, not as an instruction file or a guarantee of as-built dimensions.

Manufacturer references checked:

- FEETECH STS3215 7.4 V datasheet: https://files.seeedstudio.com/products/Feetech/108090023_STS3215-C001_Datasheet.pdf
- Waveshare Servo Driver with ESP32: https://docs.waveshare.com/Servo_Driver_with_ESP32

Key changes from the proposal: broad faceplate tape strips; bolted slots instead of dovetails; true two-piece compliant plungers; 38 mm cam; only 22 mm spacing; open board tray; enlarged accessible spring stack; separate named bodies in the existing part document. No manufacturer STEP model was imported. Hardware references are simplified envelopes.
